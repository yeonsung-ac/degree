# DEGREE

학생 작품 전시관. GitHub Pages의 main 브랜치 루트에서 제공됩니다.

- 전시관 입장: 0909 (브라우저 화면 입장 장치, 저장소 비공개 기능 아님)
- 클래스/기수/학생: data.json. 새 클래스를 classes에 추가하면 상단 전시실 구획이 자동 생성됩니다.
- order는 학번 순 정렬 번호입니다. 공개 파일에는 학번 원문을 넣지 않습니다.
- 기본 이미지: assets/consumer/*.webp. 메인페이지가 없는 경우 assets/upload-placeholder.svg.
- 학생 수정: 본인 카드의 썸네일 수정 → 개인 수정코드 → 이미지 업로드. 800×500 JPEG로 압축하여 Firebase에 저장합니다. 코드가 확인된 카드만 수정됩니다.
- 교수 관리: dasahee@yeonsung.ac.kr Google 계정. 수정코드 조회 및 최초 등록 지원.
- Firebase 규칙: backend/degree.rules는 기존 규칙 안에 추가한 전시관 전용 부분입니다. 기존 프로젝트 전체 규칙을 이 파일로 대체하지 마세요.
- 코드 파일과 학생별 학번 원본은 공개 저장소에 포함하지 않습니다.

## 학생 영상

하단에 학번 순 고정 슬롯을 제공합니다. 영상 등록에서 같은 개인 수정코드를 사용해 썸네일과 유튜브 링크를 제출합니다. 링크는 유튜브 영상 ID로 정규화하여 저장하고, 재생 버튼을 누르면 해당 슬롯 안에서 youtube-nocookie.com iframe으로 재생됩니다. 공개/일부공개 및 외부 임베드 허용 영상이 필요합니다. 학생은 본인 영상과 썸네일만 수정할 수 있고, 홈페이지 주소/성명/순서는 고정입니다.

## 추천 앱 특별 코너

페이지 가장 아래에 모든 클래스가 공유하는 추천 앱 코너를 둡니다. data.json의 recommendedApps에 제목·설명·URL·이미지를 추가하면 같은 크기의 카드로 전시됩니다. 학생 업로드 권한과 분리된 고정 콘텐츠입니다.

모든 학생·교수 업로드는 최초 업로드 시간(createdAt)과 최종 수정 시간(updatedAt)을 서버 시각으로 보존합니다. 재등록 시 최초 시간을 유지하며 카드에 수정 라벨과 한국시간 날짜·시간을 표시합니다.

## 코드 배포 없이 로그인하여 수정하기

### 교수님
1. 전시관에 0909로 입장하고 클래스를 선택합니다.
2. 교수 관리에서 dasahee@yeonsung.ac.kr 계정으로 로그인합니다.
3. 학생 본인 연결 요청에서 수업 중 학생의 이름·학번·구글 계정을 확인하고 승인합니다. 학번이 출석부와 다르면 승인이 차단됩니다.
4. 학생에게 승인됐다고 알려주면 됩니다. 코드나 이메일을 개별로 보낼 필요가 없습니다.

### 학생
1. 0909로 입장한 뒤 본인 클래스를 선택합니다.
2. 학생 로그인에서 본인 구글 계정으로 로그인합니다.
3. 첫 방문에만 출석부의 이름을 선택하고 학번 10자리를 입력해 본인 연결 요청을 보냅니다.
4. 교수님 승인 후 본인 카드의 썸네일 수정 또는 영상 등록을 사용합니다. 개인 코드는 자동 적용됩니다.
5. 다른 계정으로 로그인했다면 계정 바꾸기를 사용합니다.

연결 요청과 승인 정보는 Firebase의 degreeJoinRequests, degreeUserAccess에 저장하며, 학생은 본인 정보만 읽고 교수님만 승인할 수 있습니다. 기존 수업 도우미의 성적·제출 기록은 변경하지 않습니다.

## 입장과 등록 기록

입장 순서: 0909 → 구글 로그인 → 첫 방문 본인 연결 요청 → 지도교수 승인 → 전시관 열람. 교수 계정은 승인 없이 모든 클래스를 열람하고 모든 학생 자료를 등록·수정할 수 있습니다.

자료에는 최초 등록자·최초 업로드 시간과 최종 수정자·수정 시간을 함께 보존합니다. 교수님이 학생 대신 등록하면 '이현구(지도교수) · 대리 등록', 수정하면 '대리 수정'으로 표시됩니다. 행위자 이름과 역할은 Firebase 규칙으로 검증합니다. 예전 기록에 등록자 정보가 없다면 이름을 추측하지 않고 미기록으로 표시합니다.
